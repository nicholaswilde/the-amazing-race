# Domain Terminology & Acronyms

## Rule
In this repository and all user prompts, the acronym **TAR** refers to **The Amazing Race** (television reality competition series).

## Guidelines
1. **Never Confuse with Unix `tar`**: Do not interpret "TAR" or "tar" in dataset, CLI, issue, or prompt contexts as the Unix archive utility/tarball (`tar -czf`, `.tar.gz`).
2. **Naming Conventions**:
   - Python package: `tar_dataset`
   - CLI application: `tar-dataset`
   - Data files and tables: `tar_*` (e.g., `tar_qa_finetuning.jsonl`, `tar_knowledge_corpus.jsonl`)
3. **Common TAR Domain Acronyms**:
   - **TAR**: The Amazing Race
   - **NEL**: Non-Elimination Leg
   - **FF**: Fast Forward
   - **RB**: Roadblock
   - **DET**: Detour
   - **UT**: U-Turn (Single, Blind, Double, or Blind Wave)
   - **SB**: Speed Bump
   - **XP**: Express Pass
